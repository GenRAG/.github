# GenRAG

**Vos documents éparpillés, enfin connectés.**

GenRAG est une plateforme sans code pour créer un assistant IA qui répond à partir des documents de votre entreprise, sources à l'appui.

- Hébergé en France, données et connexions chiffrées
- Aucun modèle d'IA ne conserve vos données : vos documents n'entraînent aucune IA
- Plus de 400 modèles, avec le modèle de votre choix à chaque étape
